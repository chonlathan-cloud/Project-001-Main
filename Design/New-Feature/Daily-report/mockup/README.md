# Rayadee Site Report Interactive Mockup

This is a local, front-end-only prototype for testing the proposed worker → PM → client workflow.

## Run

```powershell
& "C:\Users\thame\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe" server.mjs
```

Open `http://127.0.0.1:4173`.

## Trial path

1. Start in the Site Worker view and create a Daily Site Report.
2. Select local media or continue to use mock evidence.
3. Complete the checklist and submit.
4. Wait for the simulated AI draft, then switch to Project Manager.
5. Review the evidence, edit the draft, confirm the approval checkbox, and publish.
6. Open the Client view, acknowledge, or ask a report-linked question.

No data is uploaded. Local files are rendered through browser object URLs only and disappear when the page closes or the demo is reset.

Visual styling is a provisional product direction, not an approved Rayadee visual identity standard.
